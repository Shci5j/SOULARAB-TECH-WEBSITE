# SOULARAB-TECH-WEBSITE

Official bilingual website for **SOULARAB TECH — Ideas Into Digital Reality**.

## Features
- Arabic and English language toggle with saved preference
- Responsive mobile-first layout
- Services, studio introduction, work showcase, process and contact sections
- WhatsApp inquiry form with a pre-filled project brief
- Official brand logo asset: `soularab-logo.png`

## Run locally
This is a static website. Open `index.html` in a browser or serve the folder with any static web server.
